# Kombi Basınç Düşüşü Kriz Masası

> Resmi sınıflandırma: **ısınmıyor ama tutanak ısınıyor.**

Bu depo, evdeki kombin bar göstergesinin 1.0'in altına inmesiyle toplanan, petek ıslığını delil, hava alma anahtarını tanık sayan bir kriz masasıdır. Bilimsel değildir. Çalışır. Gereksizdir. Patates içermez.

## Neden var?

Çünkü kış gelince herkes aynı cümleyi kurar: "Dün çalışıyordu." Bu cümle, bu kurumda suç itirafı değil, meteorolojik şiirdir.

## Kurulum

Python 3 yeter. Bağımlılık yoktur. Kombi servisi de yoktur.

```bash
python3 kriz_masasi.py --basinc 0.6 --petek islik --musluk damla
```

## Örnek karar

Bar 0.6 ise durum **turuncu islik**tir. Önerilen eylem: havluyu petekten al, suyu komşudan isteme, manometreye bakarken ciddi bir yüz ifadesi takın. Su basma işlemi bu yazılımın görev alanı dışındadır; yazılım sadece suçlar.

## Protokol

1. Manometreye bak.
2. Manometreye tekrar bak. İkinci bakış yasal zorunluluktur.
3. "Hava yapmıştır" tezi ile "usta gelecek" tezi oylanır. Oylar eşitse ıslık kazanır.
4. Tutanak imzalanır. İmza yerine petek vidası çevrilebilir.

## Gizli ek
